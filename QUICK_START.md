# Fastest Screenshot Cleaner — quick start

## Goal

Complete one small, verifiable task before using the workflow for a larger project.

## Before you begin

Use the current product from the official source. Check its device requirements and entitlements; a free download does not necessarily mean every operation is free. The feature table records product-specific limits.

## Steps

1. Allow Photos access appropriate to the screenshots you intend to review.

2. Run a scan and start with a small group rather than selecting the whole library.

3. Open similar items and check dates, text and any differences worth keeping.

4. Confirm the selection, then read the system Photos deletion prompt.

5. Check the library and available storage afterward; do not assume an estimate equals immediate reclaimed space.

## Verify the result

Return to the saved output or record rather than relying only on the preview. Check the specific items described in the steps above. If the result differs, keep the original input and reproduce the issue with a small, non-sensitive example.
