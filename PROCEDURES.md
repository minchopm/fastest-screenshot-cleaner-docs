# Fastest Screenshot Cleaner — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Review visually similar screenshots

### Before you begin

Use a small group and keep important records elsewhere.

### Steps

1. Compare text, date and visible status in each candidate.

2. Check annotations or values that differ despite similar layout.

3. Choose which copy to keep; newest is not always the correct record.

4. Review the selected deletion count.

5. Read and confirm the Photos prompt only for the intended items.

### Expected result

Only copies you have inspected are selected for removal.

### If the result differs

A similarity grouping is not proof of redundancy. Storage estimates may not equal immediately reclaimed space.

## Procedure 2: Check a stale widget estimate

### Before you begin

Open the app rather than deleting based on widget numbers.

### Steps

1. Run a new scan with the intended Photos permissions.

2. Compare the review-screen count with the widget.

3. Inspect any large or recent groups.

4. Delete only reviewed selections if desired.

5. Recheck the app after the Photos operation.

### Expected result

Decisions use current scan information.

### If the result differs

Background refresh is not background deletion. Photos Recently Deleted and system storage accounting can delay visible changes.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
